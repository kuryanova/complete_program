Перенос старых тренировок в workouts

На твоем скрине правильное место для тренировок уже есть: users / uid / trackers / workouts. Этот файл перенесет старые данные туда.

Ищем старые данные здесь:
users / lesya
users / леся
пользователи / леся

Записываем сюда:
users / твой uid / trackers / workouts

Перед заменой делаем резервную копию текущего workouts:
users / твой uid / trackers / workouts_backup_before_replace

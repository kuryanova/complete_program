Перенос тренировок в «трекеры»

Этот файл возьмет старые данные из документа пользователи / леся и запишет их в нужное место внутри «трекеров». Новые данные тренировок будут заменены старыми.

Откуда берем:
пользователи / леся

Куда записываем:
пользователи / твой uid / трекеры / тренировки

Резервная копия текущего документа «тренировки»:
пользователи / твой uid / трекеры / тренировки_backup_before_legacy_replace
